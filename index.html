Research software · In developmentPython · Numerical analysis

Scientific Analysis Engine

A computational research system for turning mathematical questions into repeatable numerical experiments. It combines automated validation, known-answer controls, and independently checked results—keeping a clear distinction between what the calculations establish and what remains unresolved.

Reproducible experimentsNumerical validationIndependent checksResource-bounded runs
Inside the engine ↗

Design the experiment

Define the mathematical target, control cases, evaluation criteria, and resource limits before interpreting a result.

Test the machinery

Check numerical methods against known answers and keep development samples separate from independent evaluation.

Preserve the evidence

Retain scripts, settings, numerical outputs, and audit records so a calculation can be reconstructed and reviewed.

Report the limits

Record inconclusive and resource-limited outcomes explicitly. A completed run is not automatically a scientific conclusion.

Private engineering project · In developmentNode.js · Static sites · Hugo

Release Fabric

A release-integrity system for families of multilingual websites. It checks that translations stay aligned with their source, links and metadata point to the right pages and languages, and builds reproduce consistently—turning release checks into a repeatable engineering process.

Translation freshnessCross-site validationReproducible buildsDeterministic evidence
Inside Release Fabric ↗

One release contract

A shared manifest describes the sites, languages, build settings, and explicit exceptions that belong to a release.

Catch drift early

Checks identify stale translations, missing content, changed placeholders, and links or metadata that point to the wrong locale.

Stage and verify

Changes are planned and built in a separate staged result. Source repositories remain untouched, with fingerprints checked throughout the run.

Evidence before publication

The system records a deterministic integrity decision. A passing check supports a release decision; publication remains a separate human-controlled step.
